How to start reading

  • Select text on any page and press Shift+R.
  • Select text, right-click, choose Speed read selection.
  • Click the toolbar icon and use Read selection on this page, or paste text in.
  • Or use the browser shortcut Alt+Shift+R (rebindable at chrome://extensions/shortcuts).

Keys while reading

SpacePlay / pause
A SSlower / faster (hold Shift for bigger steps)
← →One word back / forward
↑ ↓Previous / next sentence
Home EndJump to the start / end
EscClose the reader
